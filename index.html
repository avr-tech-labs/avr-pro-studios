AVR Pro Studios — Help

🎨 Tools

Choose tools from the tools panel. Each tool has unique behavior — Brush for smooth lines, Pencil for sharp edges, Marker for bold strokes, Neon for glowing effects.

📱 Mobile Usage

Tap 🖌️ to open Tools panel (slides from top). Tap ⚙️ to open Settings panel (slides from bottom). Tap canvas to close both.

⌨️ Shortcuts

Press B Brush, N Pencil, M Marker, E Eraser, L Line, R Rect, C Circle, F Fill.

💾 Save & Load

Download PNG or save project as .json to edit later. Import any image to draw over it.

✨ Pro Tips

  • Enable Mirror Mode for symmetric designs
  • Use Neon tool for glowing effects
  • Adjust Opacity for layered drawings
  • Use Zoom controls for precision work
